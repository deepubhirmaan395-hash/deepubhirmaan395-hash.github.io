## Portfolio website
The `index.html` file is a responsive personal portfolio website. It uses plain HTML and CSS, so it can be hosted free with GitHub Pages.

### Publish using GitHub Pages
1. Create a public repository named `deepubhirmaan395-hash.github.io` (if that exact name is available for your account).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the website. The usual URL format is `https://deepubhirmaan395-hash.github.io/`.
